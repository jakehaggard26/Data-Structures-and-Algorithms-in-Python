# Data-Structures-and-Algorithms-in-Python

## About this Project
This project is purely an educational exercise to brush up on DS&A topics and Python Package creation. At any point you think "Oh this would be great to add in my project!", take a step back, ask yourself why, and just use any real productionalized Data-Structure and/or Algorithm projects. Everything in here is implemented to work but not really tested for real-world scenarios as that would be too time consuming.

## Project Organization
I try to group similar topics together (ex: Collections will store Lists, Queues, Stacks, Trees, etc...) but each sub-topic will have its own directory. Each topic/sub-topic will have a counterpart for testing and example usage. These are to ensure their functionality and utility.
